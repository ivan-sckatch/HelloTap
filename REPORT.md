# Практическая работа № 1 «Hello Tap»

Дисциплина: «Программирование мобильных игр». Проект: HelloTap_Skachkov41.

## Цель

Создать первое приложение Unity для Android, настроить адаптивный интерфейс,
реализовать обработку нажатий и подготовить APK.

## Реализация

Проект использует Unity 6000.6.3f1 и 2D URP. Сцена HelloTap содержит камеру,
Canvas, EventSystem, заголовок, счётчик и две кнопки. Canvas Scaler настроен
на Scale With Screen Size с разрешением 1080 × 1920 и Match 0.5. Заголовок
привязан к верхней части экрана, счётчик к центральной, кнопки к нижней.
Компонент SafeArea учитывает область экрана, свободную от системных панелей и вырезов.

TapCounter хранит число нажатий и обновляет TextMeshPro. Кнопка «Тапни меня»
вызывает Increment(), кнопка «Сброс» вызывает ResetCount(). Цвет текста меняется
каждые 10 очков. Значение сохраняется в PlayerPrefs и загружается в Start().
При уходе приложения в фон данные записываются на диск. При достижении
максимального значения int дальнейшие нажатия не вызывают переполнение.

Для Android выбраны портретная ориентация, минимальная версия Android 8.0,
архитектуры ARM64 и ARMv7, IL2CPP и идентификатор com.skachkov41.hellotap.
Редакторская команда Hello Tap > Build Android APK собирает установочный файл.

## Проверка

Редакторская проверка моделирует 10 нажатий через EventSystem, проверяет цвет
счёта, сохранение при паузе, загрузку при старте и сброс через кнопку. Дополнительно
проверяются отрицательное сохранённое значение и защита от переполнения.
Фактические результаты записываются в Builds/Verification/results.txt;
там же находятся изображения сцены в трёх разрешениях.

Автоматическая проверка пройдена. Интерфейс просмотрен при 1080 × 1920,
720 × 1600 и 1200 × 1600: кириллица отображается, кнопки не перекрываются.
APK успешно собран; подпись APK Signature Scheme v2 проверена утилитой apksigner.
В установочном файле присутствуют ARM64 и ARMv7; минимальный API 26, целевой API 36.

Проверка на физическом телефоне и его скриншот должны быть добавлены после
подключения Android-устройства. Изображения редакторского рендера не подтверждают
запуск на телефоне. Перед сдачей следует указать модель телефона, версию Android,
результаты проверки нажатий, сброса и восстановления счёта после перезапуска.
